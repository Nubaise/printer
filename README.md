# Campus Xerox Shop

Full Stack printer booking system built for the Campus Xerox Shop assessment.

> The complete source tree, automated tests, and original eight-commit Git history are available in the downloadable ZIP attached to the project handoff. The source archive includes a `.git` directory and can be pushed as-is to preserve the local commit history.

## Run

Requires Node.js 20+.

```bash
npm test
npm start
```

Open http://localhost:3000.

## Features

- Daily printer board for P1, P2 and P3
- Student booking form with live estimate
- Server-side validation, price and duration calculation
- Same-printer overlap prevention and student booking lookup
- Sample data based on the assessment sign-up sheet

See `docs/` in the full project archive for API and design documentation.
